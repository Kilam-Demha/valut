# 5. دابا نفهمو الخانات

هنا غادي تبدأ الصورة تبان.

فـ Decimal عندنا:

```
10
```

الخانة اليسرى عندها قيمة **10**:

```
10
││
│└── خانة الآحاد = 1
└─── خانة العشرات = 10
```

إذن:

```
1 × 10 + 0 × 1
= 10
```

---

Binary نفس الفكرة، غير الأساس تبدل.

الخانة اليسرى قيمتها **2**:

```
10
││
│└── 1
└─── 2
```

إذن:

```
1 × 2 + 0 × 1
= 2
```

وهذا هو السبب الحقيقي علاش:

```
10 Binary = 2 Decimal
```

إييه، كاينة طريقة بسيطة بزاف. خليك غير مع **جوج قواعد**: وحدة من Binary → Decimal، ووحدة من Decimal → Binary.

# 1. Binary → Decimal

### القاعدة

من **اليمين لليسار**، عطِ لكل خانة:

```
1 → 2 → 4 → 8 → 16 → 32 → 64 → ...
```

ومن بعد **جمع غير القيم اللي فوقها 1**.

### مثال

```
10110
```

كتب القيم:

```
  1   0   1   1   0
 16   8   4   2   1
```

دابا خذ غير `1`:

```
16 + 4 + 2
```

إذن:

```
10110₂ = 22₁₀
```

### اختصار تحفظو:

> **Binary → Decimal = حط 1,2,4,8... من اليمين، وجمع اللي فوق 1.**

---

# 2. Decimal → Binary

هنا عندك **أسهل طريقة للحساب اليدوي**: القسمة على 2.

كل مرة:

1. قسم الرقم على 2.
2. سجل **الباقي**: يا `0` يا `1`.
3. كمل بالقسمة على 2 حتى توصل لـ 0.
4. فالأخير **قرا البواقي من لتحت للفوق**.

### مثال: 22 → Binary

```
22 ÷ 2 = 11   الباقي 0
11 ÷ 2 = 5    الباقي 1
 5 ÷ 2 = 2    الباقي 1
 2 ÷ 2 = 1    الباقي 0
 1 ÷ 2 = 0    الباقي 1
```

البواقي بالترتيب اللي خرجو:

```
0 1 1 0 1
```

ولكن كنقراو **من لتحت للفوق**:

```
10110
```

إذن:

```
22₁₀ = 10110₂
```

---

# 3. علاش كنقراو من لتحت للفوق؟

حيت أول باقي كيعطيك **آخر bit من اليمين**.

شوف:

```
22 ÷ 2 → باقي 0  ← آخر خانة
11 ÷ 2 → باقي 1
 5 ÷ 2 → باقي 1
 2 ÷ 2 → باقي 0
 1 ÷ 2 → باقي 1  ← أول خانة
```

إذن:

```
10110
↑
هاد 1 هو أول خانة
```
